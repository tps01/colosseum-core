# Archived planning documents

These ADRs, feature overviews (FFO), and detailed design documents (DDD) record early Colosseum planning and rationale. They are **not normative** for current behavior.

When changing the product, prefer in order:

1. [scope.md](../../scope.md) — implemented behavior and deferred items
2. [Sphinx user guides](../../sphinx/source/guides/)
3. [examples/](../../../examples/) and tests
4. Generated **Bench configuration reference** (`python scripts/docgen/build_all.py`)
5. Source code

Subdirectories:

| Path | Contents |
|------|----------|
| [decisions/](decisions/) | Architecture decision records (ADR) |
| [features/](features/) | Feature overviews (FFO) |
| [design/](design/) | Detailed design documents (DDD) |

Older files removed before this archive layout are listed in [../MANIFEST.md](../MANIFEST.md).
